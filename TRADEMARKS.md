"Omit OS" — the name, and any logo the project adopts — identifies this
project and what it releases. They are claimed as trademarks of the
project. (The name is provisional, as the README says; this policy
applies to whatever name the project carries. No logo exists yet, and
nothing has been registered.)

The licences in this repository cover code and documentation. **They do
not grant any right to use the project's name or logo.**

You may, without asking:

- say truthfully that your software runs on, is built for, or is derived
  from Omit OS;
- use the name to refer to the project in articles, reviews, talks and
  documentation;
- redistribute unmodified official releases under their name.

You may not, without permission:

- distribute a modified version — a fork, a rebuild with changes, a
  derived system — under the name "Omit OS" or a confusingly similar
  one. **Forks must be renamed**, and should say what they are derived
  from;
- use the name or logo in a way that suggests the project endorses or
  is responsible for something it is not;
- register the name, or one confusingly similar, as a trademark, domain
  or organisation name.

This page states the project's intent. It has not been reviewed by a
lawyer, and it is not a substitute for a registered mark or a formal
trademark policy.
