# Trademarks

## The project's own marks

"Omit OS" — the name, any logo the project adopts, and the mark on its
Start/launcher button — identify this project and what it releases.
They are claimed as trademarks of the project. (The name is provisional,
as the README says; this policy applies to whatever name the project
carries. The launcher mark is the ring with one segment omitted, and
the dot that is left, shown at the left of the task bar. There is no
other logo yet, and nothing has been registered.)

The licences in this repository (GPL, MIT, Apache, CC-BY-SA; see
[`COPYING`](COPYING)) cover code, documentation and artwork. **They do
not grant any right to use the project's name, logo or launcher mark.**

### Allowed without asking

- redistributing **unmodified official builds** under their name;
- using the name in **news, reviews, tutorials**, talks and
  documentation;
- saying truthfully that something **"works with Omit OS"**, runs on it
  or is built for it;
- **linking** to the project.

### Not allowed without permission

- distributing a modified version — a fork, a rebuild with changes, a
  derived system — under the name "Omit OS", its logo or launcher mark,
  or anything confusingly similar. **Forks and modified distributions
  must remove the name and logo and use their own branding**; they may
  say that they are "based on Omit OS";
- using the name or marks in a way that suggests the project endorses
  or is responsible for something it is not;
- registering the name, or one confusingly similar, as a trademark,
  domain or organisation name.

## Other people's marks

Windows and Microsoft are trademarks of Microsoft Corporation; macOS and
Apple are trademarks of Apple Inc.; Linux is a trademark of Linus
Torvalds. These and all other third-party marks belong to their owners.
They appear in this project only nominatively — to say what the system
is compatible with, or what a piece of code was written to interoperate
with — and never as the name of anything of ours. Omit OS is not
affiliated with, sponsored by, or endorsed by any of their owners.

The rules that keep it that way in the code and the user interface are
in [`CONTRIBUTING.md`](CONTRIBUTING.md); bundled third-party assets are
listed in [`ATTRIBUTION.md`](ATTRIBUTION.md).
